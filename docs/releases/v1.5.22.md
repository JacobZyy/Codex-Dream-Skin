# Codex Dream Skin v1.5.22

**中文** · [English](https://github.com/JacobZyy/Codex-Dream-Skin/blob/v1.5.22/docs/releases/v1.5.22-en.md)

本 fork 新增可选的本地可信 `theme.js`，让主题作者在原生 Codex 页面上管理自己的装饰、布局和图片加载生命周期。普通图片/CSS 主题沿用原有方式，无需添加脚本或授信。

本页描述 v1.5.22 的变更；版本与安装包是否已公开，请以 [fork Releases](https://github.com/JacobZyy/Codex-Dream-Skin/releases) 为准。

## 新增功能

- **主题自带脚本**：macOS 与 Windows 可随主题保存、切换和恢复一个可选 `theme.js`。`theme.json` 保持 `schemaVersion: 1`，通过 `"script": "theme.js"` 启用，无需改动官方应用文件。
- **按内容显式授信**：导入只加入已保存主题，不执行脚本或自动授信。审查完整代码后，使用 `--trust-theme-script --theme-dir <已审查的主题目录>` 对精确 SHA-256 授信，再选择主题应用。授信命令本身不执行脚本，修改字节后须重新审查和授信新 hash。
- **切换、重载与恢复**：脚本每代只运行一次。A → B → A 会清理上一代并重新运行 A；页面重载后重新挂载当前可信脚本；恢复原状时先发出中止信号，再执行脚本登记的清理函数。脚本可返回 Promise 等待图片加载等准备工作，未完成或失败时不会被报告为渲染成功。

## 修复与改进

- **macOS 热切换**：刷新只处理已完成初始化的窗口，等待进行中的连接并在异步步骤后复核窗口身份，避免辅助窗口导致重复失败或沿用旧的页面重载脚本。
- **旧主题名称兼容**：名称包含脚本槽位字面量时仍可正常加载，不会误判为模板未替换。

- **主题内容一致性**：双端主题复制、保存替换、内容指纹、监听刷新、快照与回滚包含声明的脚本，避免切换后遗漏脚本或继续使用旧内容。
- **包校验**：脚本必须为非空 UTF-8、最大 6 MiB，并通过语法解析及 manifest 字节数/SHA-256 校验。静态 `--check-payload` 只解析，不执行脚本；既有路径、链接、归档、图片和 Safe CSS 校验继续生效。

## 升级与使用

脚本包必须登记 `theme.js` 的 `application/javascript` 媒体类型，使用 `skinApiVersion: 2`、声明 `theme-script` 能力，并要求 `minClientVersion` 至少为 `1.5.22`。本地简化三文件 ZIP 不接受脚本。具体授信命令与 API 见[可信主题脚本文档](https://github.com/JacobZyy/Codex-Dream-Skin/blob/v1.5.22/docs/theme-scripts.md)。

第三方脚本拥有 Codex 页面和聊天内容的访问权限，脚本 API 不是沙箱。作者须登记全部节点、监听器、观察器、动画、URL 与原生样式变更的清理，并在异步回调中检查中止信号；客户端无法撤销任意未登记的页面修改。只对已审查的精确内容授信。

此能力属于本 fork。现有上游客户端及 DreamSkin.cc 在线图库/Studio 尚不支持可执行主题包；旧客户端应拒绝 API 2 / 最低版本 1.5.22 的包。本地实现与测试不代表图库支持或公开发布。
